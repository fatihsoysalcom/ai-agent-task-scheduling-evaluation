# AI Agent Task Scheduling Evaluation

This example demonstrates the difference between observability and evaluation in AI agents. It simulates a task scheduling AI agent that processes tasks with varying priorities and efforts under a resource budget. The first phase shows the agent's actions (observability), while the second phase introduces an evaluation mechanism to measure how well the agent performed against defined goals and an optimal baseline.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
